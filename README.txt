DIGITALE VERK – KOMPLETT NETTSIDE V4

Hovedbudskap:
- Digitale Verk kan effektivisere én konkret oppgave.
- Digitale Verk kan også utvikle komplette systemer for hele bedriften.
- Løsningene bygges rundt arbeidsflyten, ikke rundt et standardprodukt.

Innhold:
- Ny, ryddig forside med lite gjentakelse.
- Oversikt over mulige moduler og systemområder.
- Arbeidsflyt og automatisering forklart visuelt.
- Tre brede, interaktive eksempler:
  1. Serviceflyt
  2. Kursportal
  3. Bedriftsnav
- Nøytrale eksempeldata.
- Mobiltilpasset design.
- Kontaktskjema via FormSubmit.

Slik bruker du:
1. Pakk ut ZIP-filen.
2. Last opp hele mappen.
3. Åpne index.html.
4. Bruk Ctrl + Shift + R hvis nettleseren viser en gammel versjon.
